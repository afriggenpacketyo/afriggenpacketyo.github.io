Thousands of compromised websites used in malware distribution scheme

2026-09-13 14:30:18 EDT

Security researchers have identified over 5,400 websites, many belonging to small businesses, that have been compromised to spread malware. Attackers are using a technique called ClickFix, which presents a fake CAPTCHA that instructs users to open Windows Run and paste a command. This command downloads and installs malicious software onto the user's computer. The attackers are leveraging the BNB Smart Chain test network to store instructions, making the malicious infrastructure harder to shut down. A newer version of the attack bypasses the fake CAPTCHA by using WebRTC to create an encrypted data connection. Users are advised never to paste computer commands from websites and to maintain strong antivirus protection and updated software to mitigate these threats. The advice includes disconnecting from the internet if a command has been run and changing passwords for sensitive accounts.
